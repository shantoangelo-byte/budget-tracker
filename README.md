# Budget Tracker 💰

## Project Overview

Budget Tracker is a simple and responsive web project designed to help users
organize their income, expenses, and savings.

The project focuses on creating a clean and easy-to-use interface where a
user can view their budget and understand their spending.

For this week's project, I built the front-end structure of the Budget

The current website includes:

- A navigation bar

- Total income section
- Total expenses section
- Total savings section
- Recent transactions
- About the project section
- A "Coming Next" section
- Responsive design for different screen sizes
- A clear page title
- A favicon
- Open Graph meta tags
- A meta description
- GitHub Pages deployment
